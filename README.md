# Moda Mirror

**Moda Mirror** is a stylish and interactive Smart Mirror interface that combines fashion, time, weather, daily quotes, and wardrobe management in one sleek web-based app. It’s designed to run directly in a browser and can be used on mobile, tablet, or desktop.

## Features

- **Live Clock & Date** – Displays current time and date.
- **Daily Weather & Quote** – Static placeholders you can customize or link to live APIs.
- **Wardrobe Tracker** – Add, edit, and delete wardrobe items.
- **Random Outfit Generator** – Suggests a complete outfit from your wardrobe.
- **Clean, Modern UI** – Beautiful layout with a stylish Google Font and responsive design.

## How to Use

1. **Open `index.html` in any browser** – No server or internet connection required.
2. **Add Your Wardrobe Items** – Enter clothing items and categorize them by type.
3. **Tap ‘Random Outfit’** – Get a surprise style combo from your personal wardrobe.
4. **Customize Weather and Quote** – Replace the placeholder text with your own or connect to an API.

## Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- Google Fonts

## Installation

You can run it locally by simply opening `index.html`. Or host it online using GitHub Pages:

1. Fork or clone this repo  
2. Upload `index.html`  
3. Go to **Settings > Pages** and enable GitHub Pages on the `main` branch  
4. Share the live link!
